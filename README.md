# offline_sync_queue

A Dart/Flutter package that queues actions while the device is offline and syncs them reliably when it reconnects.

> 🚧 In progress, planned release on pub.dev in January 2027

## Planned features

- Persistent queue that survives app restarts
- Automatic retry with exponential backoff
- Connectivity-aware syncing
- Simple, typed API with tests and an example app
